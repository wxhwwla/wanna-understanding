# Wanna Understanding — 操作指令集

> 日常开发、测试、部署的常用命令速查。

---

## 环境与依赖

> **注意**：本应用需要在 DPI 感知模式下运行。`tcl_bootstrap.py` 已在导入时自动调用
> `SetProcessDPIAware()`。如果从其他入口点启动而未加载此模块，窗口在 HiDPI 屏幕上
> 会只占左上角 2/3。

```powershell
# 创建虚拟环境（Windows）
$env:PYTHONUTF8 = "1"
chcp 65001 > $null
python -m venv .venv
.venv\Scripts\activate

# 安装依赖
pip install -e ".[dev]"

# 安装全部依赖
pip install -e ".[dev,build]"
```

---

## 测试

```powershell
# 全量测试
pytest

# 指定模块
pytest tests/module_a/ -q

# 带覆盖率
pytest --cov=src --cov-report=term

# 慢测跳过
pytest -m "not slow"
```

## 代码检查

```powershell
# Lint
ruff check .

# 格式化
ruff format .

# 类型检查
pyright
```

## Git 操作

```powershell

git status

# 查看未提交的 diff
git diff

git add .
```

## 日志查看

```powershell
# 运行时日志（文件自动轮转 3×1MB, UTF-8）
Get-Content "$env:APPDATA\WannaUnderstanding\logs\wanna_understanding.log" -Tail 50 -Encoding UTF8

# 实时跟踪
Get-Content "$env:APPDATA\WannaUnderstanding\logs\wanna_understanding.log" -Tail 0 -Wait -Encoding UTF8
```

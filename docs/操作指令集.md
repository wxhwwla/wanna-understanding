# Wanna Understanding — 操作指令集

> 日常开发、测试、部署的常用命令速查。

---

## 环境与依赖

```powershell
# 创建虚拟环境（Windows）
$env:PYTHONUTF8 = "1"
chcp 65001 > $null
python -m venv .venv
.venv\Scripts\activate

# 安装依赖
pip install -e ".[dev]"

# 安装全部依赖
pip install -e ".[dev,build]"
```

---

## 测试

```powershell
# 全量测试
pytest

# 指定模块
pytest tests/module_a/ -q

# 带覆盖率
pytest --cov=src --cov-report=term

# 慢测跳过
pytest -m "not slow"
```

---

## 代码检查

```powershell
# Lint
ruff check .

# 格式化
ruff format .

# 类型检查
pyright
```

---

## Git 操作

```powershell
# 查看状态
git status

# 查看未提交的 diff
git diff

# 提交
git add .
git commit -m "描述改动内容"
git push
```

---

## 项目维护

```powershell
# 清理缓存
Remove-Item -Recurse -Force __pycache__/, .pytest_cache/, .ruff_cache/
```

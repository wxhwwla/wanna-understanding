# Wanna Understanding — 依赖说明

> 本文档记录项目依赖的选择理由和注意事项。

---

## 核心依赖

| 包 | 用途 | 选择理由 | 替代方案 |
|------|------|----------|----------|
| **mss** | 屏幕截图 | 纯 C 实现，速度极快，跨平台 | PIL.ImageGrab（慢） |
| **pywin32** | Windows API | 获取窗口句柄、DPI、窗口矩形 | （Windows 必须） |
| **paddleocr** | 文字识别 | 代码 OCR 准确率最高（支持中英文和特殊符号） | Tesseract（慢不准）、EasyOCR（稍差） |
| **paddlepaddle** | PaddleOCR 后端 | PaddleOCR 的推理框架 | （必须伴随 paddleocr 安装） |
| **httpx** | HTTP 客户端 | 支持流式输出、异步、连接复用 | requests（不支持流式） |
| **pydantic** | 数据模型 | 结构化输出解析、类型校验 | dataclasses（校验弱） |

## 开发依赖

| 包 | 用途 |
|------|------|
| pytest | 测试框架 |
| pytest-cov | 覆盖率报告 |
| ruff | Lint + 格式化 |
| pyright | 类型检查 |

## 安装方式

```bash
# 核心依赖（生产运行）
pip install mss pywin32 paddleocr paddlepaddle httpx pydantic

# 完整开发环境
pip install -e ".[dev]"
```

## 许可检查

每次新增第三方依赖时，必须确认其许可证与项目 MIT 许可兼容：

| 许可 | 兼容性 | 说明 |
|------|:----:|------|
| MIT / BSD / Apache 2.0 | ✅ | 自由使用 |
| LGPL | ✅ | 动态链接可接受 |
| GPL / AGPL | ❌ | 传染性过强，禁止 |
| SSPL / 自定义 | ❌ | 权利不明或商业受限 |

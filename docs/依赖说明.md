# Wanna Understanding — 依赖说明

> 本文档记录项目依赖的选择理由和注意事项。

---

## 核心依赖

| 包 | 用途 | 选择理由 | 替代方案 |
|------|------|----------|----------|
| **mss** | 屏幕截图 | 纯 C 实现，速度极快，跨平台 | PIL.ImageGrab（慢） |
| **pywin32** | Windows API | 获取窗口句柄、DPI、窗口矩形 | （Windows 必须） |
| **Pillow** | 图像预处理 | 灰度/二值化/反色管线 | OpenCV（依赖更重） |
| **httpx** | HTTP 客户端 | 支持流式输出、异步、连接复用 | requests（不支持流式） |
| **pydantic** | 数据模型 | 结构化输出解析、类型校验 | dataclasses（校验弱） |

## OCR 可选依赖（`[ocr]`）

| 包 | 用途 | 选择理由 |
|------|------|----------|
| **easyocr** | 文字识别 | 复用 `endfield_damage_calculator` 成熟封装，安装比 PaddleOCR 轻 |
| **numpy** | 数组转换 | EasyOCR 输入格式 |

OCR 实现位于 `src/wanna_understanding/ocr/recognizer.py`，改编自
`endfield_damage_calculator/tools/ocr/recognizer.py`。

## 开发依赖

| 包 | 用途 |
|------|------|
| pytest | 测试框架 |
| pytest-cov | 覆盖率报告 |
| ruff | Lint + 格式化 |
| pyright | 类型检查 |

## 安装方式

```bash
# 核心依赖（不含 OCR）
pip install -e .

# 完整开发 + OCR
pip install -e ".[dev,ocr]"

# 预下载 EasyOCR 模型（国内网络慢时加 --mirror）
python scripts/ocr_download_models.py
python scripts/ocr_download_models.py --mirror
```

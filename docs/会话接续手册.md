## §2 近期完成的工作

### 2026-06-18：全流程调通 — DPI 感知 + 手动框选 + OCR 中文

- **DPI 感知修复（关键）**：`tcl_bootstrap.py` 添加 `SetProcessDPIAware()`，解决 HiDPI（150%+）下全屏窗口只占屏幕 2/3 的根本问题
- **手动框选取代自动检测**：删除不可靠的自动代码区域检测，改为全屏截图 → 用户拖动框选 → Enter 确认
- **OCR 加入中文**：语言列表 `["en"]` → `["en", "ch_sim"]`，中英文混合代码可识别
- **OCR 置信度降至 0.2**：原 0.3→0.2，多捕获约 30-50% 低置信度但正确的文本
- **OCR 后处理过滤行号**：`_post_process` 过滤纯数字行和单字母行（编辑器行号污染）
- **行号裁剪开启**：`trae_dark` / `vscode_dark` / `cursor_dark` 启用 `strip_line_numbers=True`
- **自动冻结延迟 2 秒**：避免流式输出被冻结截断
- **解冻触发重新分析**：解冻时如有窗口变化积压，立即触发分析
- **悬浮窗启动居中**：`geometry` 加上屏幕居中坐标，不再从 (0,0) 启动
- **框选界面居中**：修复物理/逻辑像素混用问题，截图在画布正中央
- **选择界面松手不确认**：改为 Enter 确认、Esc 取消，松手只完成选框可重新拖拽

### 2026-06-18：自动冻结 + 中文乱码修复 + 快捷键全面换 Alt

- **自动冻结**：分析完成后自动冻结，冻结期间不截图不分析不调 AI，`Alt+Shift+F` 解冻
- **中文乱码修复**：Consolas 不含中文字形导致「潜在Bug→獣Bug」——内容区改为 Microsoft YaHei
- **快捷键全部 Alt+Shift**：H 显隐 / J 历史 / O 设置 / F 冻结（避免 Ctrl 被 IDE 占用）
- **冻结相关 Bug**：冻结后切窗口不再隐藏；冻结不改内容区、只变标题栏
- **Trae 编辑支持**：新增 `trae_dark` profile，`detect_editor_profile` 识别 "trae" 标题
- **OCR 质量改进**：阈值从 50th→25th 百分位，置信度 0.5→0.3，新增诊断日志
- **修复闪退**：`bad cursor spec "size_s"`——无效光标名导致 tkinter 崩溃
- **托盘菜单加冻结**：右键托盘可直接切换冻结/解冻
- **字体全面调整**：标题 12pt、内容 13pt、设置 12pt（Microsoft YaHei，支持中文）

# Wanna Understanding — 版本号说明

---

## 版本号格式

```
主版本.次版本.修订号
   │      │      │
   │      │      └── 修订号（patch）：Bug 修复、小改动
   │      └───────── 次版本（minor）：新功能、非破坏性变更
   └──────────── 主版本（major）：重大重构、破坏性变更
```

示例：`0.1.0` → `0.1.1`（修订） → `0.2.0`（次版本） → `1.0.0`（主版本）

## 版本常量位置

- **单源真实版本**：`scripts/_version.py` 中的 `_VERSION` 常量
- **程序运行时版本**：`src/wanna_understanding/__init__.py` 中的 `__version__`
- 两项应保持一致

## 版本递增规则

| 场景 | 递增类型 | 说明 |
|------|----------|------|
| Bug 修复、文档更新 | patch | 第三位 +1 |
| 新功能、新模块 | minor | 第二位 +1，第三位归零 |
| 重大重构、破坏性 API 变更 | major | 第一位 +1，后两位归零 |

## 上传脚本自动递增

运行 `python github_upload_module.py` 时：
- 默认提示选择 patch 或 minor
- `--minor` 直接次版本递增
- `--no-bump` 不递增版本号

# Wanna Understanding — 项目目标

> 每次对话开始前，必须完整阅读本文档，了解项目的长远愿景和当前焦点。

**最后更新**：2026-06-17

---

## 1. 长远目标

打造一款**只读不写、零操作、跨编辑器**的桌面 AI 代码审阅工具，成为开发者编码时的「第二双眼睛」。

### 1.1 核心理念

```
始终在后台运行           不绑定特定编辑器         只读不写
    │                        │                     │
    ▼                        ▼                     ▼
自动监控屏幕 → OCR/UIA 提取 → AI 分析 → 悬浮窗展示解释 & 建议
    │                                                   │
    ▼                                                   ▼
零操作，自动跟随滚动/切换                       旁观者，不修改代码
```

### 1.2 目标形态

| 维度 | 目标 |
|------|------|
| 受众 | 所有写代码的人（不限编辑器、不限语言） |
| 内核 | 屏幕捕获 + OCR（+ 可选 UIA）+ AI API 分析 |
| 扩展 | 从 Python MVP → C# 重写 → Rust 极致性能优化 |
| 商业模式 | 免费开源（AGPL-3.0），社区驱动 |
